# ATRI packaged assets

These files are local copies of every font, WebP, and GIF referenced by the
built-in ATRI report templates. They were retrieved from the template's former
asset origin, `https://tc.ciallo.ccwu.cc/file/`, on 2026-08-28.

The report generator converts matching template URLs to `data:` URIs before it
sends HTML to AstrBot T2I or writes a standalone HTML report. Do not rename an
asset without updating every matching template reference.
